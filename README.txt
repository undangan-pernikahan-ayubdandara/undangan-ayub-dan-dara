UNDANGAN PERNIKAHAN AYUB & DARA
================================

Isi folder:
- index.html: website undangan (HTML/CSS/JavaScript, tanpa database)
- assets/foto-utama.jpg: foto utama dari lampiran pertama
- assets/foto-background.jpg: foto background dari lampiran kedua

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Pastikan index.html dan folder assets berada dalam folder yang sama.
3. Klik dua kali index.html untuk melihat website di browser.
4. Untuk dipublikasikan online, unggah seluruh isi folder ke hosting statis seperti GitHub Pages, Netlify, atau Cloudflare Pages.

MENGISI FOTO MOMEN
- Pada bagian Foto Momen, klik salah satu dari 17 kotak dan pilih foto dari perangkat.
- Foto yang dipilih hanya tampil sementara di browser/perangkat tersebut; tidak tersimpan ke server atau otomatis terlihat oleh tamu lain.
- Untuk membuat 17 foto tampil bagi semua pengunjung, letakkan foto di folder assets dan edit bagian galeri pada index.html.

MENAMBAHKAN MUSIK
1. Letakkan file musik milik Anda di folder assets dengan nama music.mp3.
2. Buka index.html dengan Notepad.
3. Cari bagian audio dekat akhir file:
   <!-- <source src="assets/music.mp3" type="audio/mpeg"> -->
4. Hapus tanda komentar sehingga menjadi:
   <source src="assets/music.mp3" type="audio/mpeg">
5. Simpan. Pengunjung harus menekan tombol musik; browser biasanya tidak mengizinkan autoplay sebelum ada interaksi.

WHATSAPP
- Form ucapan membuka WhatsApp ke nomor yang diberikan dalam format internasional 6285840092584.
- Nama, konfirmasi kehadiran, dan ucapan/doa disusun lengkap otomatis lalu WhatsApp dibuka dengan teks tersebut. Pengunjung tetap harus menekan tombol Kirim di WhatsApp; website biasa tidak dapat mengirim pesan WhatsApp tanpa tindakan pengguna.
- Tidak ada database dan komentar tidak disimpan otomatis.
